# Patterns - Padrões de Design

Este diretório contém documentação de padrões de design aplicados ao desenvolvimento de jogos com Godot.

## Padrões a Documentar

### Já Implementados
- [ ] Component Pattern - Como criar componentes reutilizáveis
- [ ] Observer Pattern - EventBus e sistema de eventos
- [ ] Singleton Pattern - Autoloads e gestão global

### Planejados
- [ ] State Pattern - Máquinas de estado
- [ ] Object Pool Pattern - Pooling para performance
- [ ] Command Pattern - Para input e undo/redo
- [ ] Factory Pattern - Criação de entidades
- [ ] Service Locator - Acesso a serviços globais

## Template

Ao documentar um padrão, inclua:

1. **Nome e Classificação**: Nome do padrão e categoria (Creational, Structural, Behavioral)
2. **Problema**: Que problema resolve?
3. **Solução**: Como funciona?
4. **Estrutura**: Diagrama ou descrição da estrutura
5. **Implementação GDScript**: Código exemplo
6. **Casos de Uso**: Quando usar?
7. **Prós e Contras**: Trade-offs
8. **Exemplos no Projeto**: Onde já usamos?

## Contribuindo

Para adicionar novo padrão:
1. Crie `[nome-do-padrao].md`
2. Use estrutura consistente
3. Inclua exemplos práticos em GDScript
4. Referencie de onde é usado no projeto
